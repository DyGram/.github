# .github
Organisation-wide defaults for the `DyGram` organisation.

- `profile/README.md` — rendered on the public organisation profile page.
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md` —
  applied to repositories in this organisation that do not define their own.
- `.github/ISSUE_TEMPLATE/`, `.github/PULL_REQUEST_TEMPLATE.md` — default
  issue and pull request templates.
